# Add a page for users to suggest service centers not yet on the website

- STATUS: OPEN
- PRIORITY: 55
- TAGS: ux, feature

Create a dedicated page where authenticated users can suggest new government service centers that are not yet listed on the platform. The form should collect the center name, city, address, phone number(s), and any known services offered. Submissions should be stored and visible in the admin panel for staff review. Users should receive feedback confirming their suggestion was received and optionally be notified when the center is added to the website.

+ City field should be recieved as a string and not validated against the existing cities since it might be new city
+ This will need a card page in the admin panel
+ The UI for verifying the center in the admin panel MUST have a great UX and also allow the admins to edit the fields the way they want before adding the center to the website
