# Replace site logo with SVG or PNG image

- STATUS: OPEN
- PRIORITY: 45
- TAGS: ux, design

Replace the text-based site logo (the h1 and p elements inside the .logo anchor in the navbar) with an SVG or PNG image. The image should convey the site name and tagline visually. It must be responsive and look good on both desktop and mobile viewports. The alt text or an aria-label should be preserved for accessibility. Consider using an SVG for crisp rendering at all resolutions, with a fallback PNG for older browsers if needed.
