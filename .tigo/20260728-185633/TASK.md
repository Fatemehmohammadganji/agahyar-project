# Improve blog frontend UI/UX

- STATUS: OPEN
- PRIORITY: 80
- TAGS: feature, blog, ux, frontend

Improve the visual design and user experience of the blog list and detail pages to match modern blog standards. Areas to cover:

- Blog list: card hover effects, better typography, excerpt truncation, image placeholders, category badges, reading time and view count display on cards
- Blog detail: better article typography (drop cap, pull quotes), table of contents for long posts, progress indicator while scrolling, smooth image lightbox, improved author box
- Responsive: ensure perfect display on mobile and tablet
- Loading states: skeleton screens while images load
- Animations: subtle fade-in for cards on scroll, smooth transitions
- Empty states: better design when no posts or no search results
