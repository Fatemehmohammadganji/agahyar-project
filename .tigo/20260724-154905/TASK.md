# Show User PKs in Admin Panel

- STATUS: CLOSED
- PRIORITY: 40
- TAGS: admin, ux

Display user primary keys in the Django admin user list view so that staff can easily reference and identify specific users when managing accounts, responding to support requests, or troubleshooting issues. The PK should be visible as a column in the user change list page alongside existing fields like username, email, and last login. Consider making it sortable and searchable.
