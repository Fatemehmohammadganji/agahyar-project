# Add a page for users to submit services they want to be added

- STATUS: OPEN
- PRIORITY: 55
- TAGS: ux, feature

Create a dedicated page where authenticated users can request the addition of new government services to the platform. The form should collect the service name, a brief description, and any relevant details the user can provide (e.g. which government organization offers it, what documents are typically needed). Submissions should go into a review queue accessible from the admin panel where staff can approve, reject, or act on the request. Users should receive confirmation that their request was submitted and optionally be notified when it is processed.

+ The button to enter that page should be visible to unauthenticated users as well
+ This will need a card page in the admin panel
