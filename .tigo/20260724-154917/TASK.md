# Add blog post feature: admin writing and public publishing

- STATUS: OPEN
- PRIORITY: 60
- TAGS: feature, admin, content

Implement a blog system that allows staff to write, edit, and publish blog posts from the Django admin panel. Each blog post should have a title, slug, body content (with rich text editing support), an optional featured image, author attribution, publish date, and published/draft status. Published posts should be visible on the public website at a /blog/ listing page and individual /blog/<slug>/ detail pages. The blog should integrate with the existing site design and navigation. Consider adding RSS feed support and SEO meta tags for blog posts.
