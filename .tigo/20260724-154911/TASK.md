# Add the option for users to report service centers having services not mentioned on the website

- STATUS: OPEN
- PRIORITY: 55
- TAGS: feature, ux

Extend the existing report functionality on service center detail pages so that users can specifically report that a service center offers services not yet listed on the website. The report should allow the user to specify which unlisted service(s) they know the center provides. Reports should be visible in the admin panel for staff to review and act on, either by adding the missing services to the center or dismissing the report. This builds on the existing center reporting infrastructure.
