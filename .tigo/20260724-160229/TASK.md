# Add keyword 'آگاه یار' (space variant) to pages for SEO

- STATUS: CLOSED
- PRIORITY: 50
- TAGS: seo, feature

Add the keyword 'آگاه یار' (with a regular space instead of the half-space/fixed-width non-joiner) to the meta keywords and relevant content across all pages of the website. The existing 'آگاه‌یار' (with half-space) should be kept as well. This targets users who search with a regular space. The new variant should appear in meta keywords tags on every page, and optionally in other relevant text content where it reads naturally. This is a site-wide SEO improvement to capture both search patterns.
